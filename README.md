# MezoLens

### See Beyond Transactions. Understand Bitcoin DeFi.

MezoLens is an experimental dashboard concept designed
to make Bitcoin DeFi activity easier to explore and understand.

## Vision

Help users explore supported blockchain data through a
clear, accessible, and informative interface.

## Planned Features

- Dashboard for supported ecosystem data
- Transaction explorer with verifiable records
- Bitcoin DeFi position explorer
- Risk insights based on verified data
- MUSD activity visualization where supported

## Technology

- HTML, CSS, and JavaScript for the initial prototype
- Git and GitHub for version control
- Solidity if verified project requirements call for smart contracts

## Development Status

Early development. Features are planned and may not yet
be implemented.
